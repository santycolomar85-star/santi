## 📥 CUANDO ME PASES LOS DATOS BANCARIOS Y EL PLAZO

Te entrego la firma en **3 formatos**:

1. **Plain text** (para Outlook → Configuración → Firmas → texto sin formato)
2. **HTML** (con el CIF icon embebido + estilos inline + estructura bilingüe en tabla — máxima compatibilidad Outlook desktop / web / Mac / Gmail)
3. **PNG banner** (un solo archivo de imagen con todo, por si prefieres pegarlo como imagen única — aunque pierde clicabilidad en teléfono / email)

El HTML es lo que recomiendo: clicable + editable + funciona en todos los clientes.
