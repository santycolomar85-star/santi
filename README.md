## 🚀 INICIO RÁPIDO POR ROL

### Si eres **diseñador / generador de imágenes**:
1. Lee `01_MANUAL/MANUAL_DE_MARCA_ECUAMAN.md`
2. Copia el prompt apropiado de `02_PROMPTS/PROMPTS_MAESTROS.md`
3. Valida con `03_REFERENCIAS/CHECKLIST_VALIDACION.md` (24 puntos)
4. Sube siguiendo `COMO_SUBIR_ARCHIVOS.md`

### Si eres **community manager / copywriter**:
1. Lee `05_ESTRATEGIA/01_BIBLIA_DEL_PERSONAJE.md` (voz y personalidad)
2. Lee `05_ESTRATEGIA/04_HISTORIA_DE_VIDA_ECUAMAN.md` (lore que puedes citar)
3. Sigue `05_ESTRATEGIA/03_CALENDARIO_EDITORIAL.md` (qué publicar cuándo)
4. Inspírate con `04_USO_REDES/PLANTILLAS_CONTENIDO.md`

### Si eres **director de marca / decisor**:
1. Empieza por `05_ESTRATEGIA/02_ESTRATEGIA_DE_MARCA.md` (visión 12 meses, KPIs, presupuesto)
2. Profundiza en `05_ESTRATEGIA/04_HISTORIA_DE_VIDA_ECUAMAN.md` (la épica)
3. Aprueba mensualmente revisando `03_REFERENCIAS/CHECKLIST_VALIDACION.md`
